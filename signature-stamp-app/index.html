Demo Memerlukan Server

Demo ini berjalan dengan server Python (Flask) untuk memproses PDF. Ia tidak boleh berjalan sebagai halaman statik.

1. Buka folder demo dan jalankan:
cd signature-stamp-app
pip install -r requirements.txt
python app.py
2. Kemudian buka http://127.0.0.1:5000
(Windows: double-click run.bat terus buka app)

Selepas server jalan, muat semula halaman ini.
