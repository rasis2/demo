Module 08 · Types

Printer Types

Each technology suits different needs.

📄

Laser

Toner + drum + heat. Fast, crisp text, low cost per page.

🎨

Inkjet

Liquid ink is sprayed. Great for photos & color, low initial cost.

🔥

Thermal

Heat on sensitive paper — receipts, labels. No ink.

🔨

Impact / Dot Matrix

Pins strike an ink ribbon — multi-part (carbon) forms.

🧊

3D Printer

Additive manufacturing — build 3D objects layer by layer.

Module 08 · Laser

Laser Printer Components

The main parts of a laser printer.

🖤

Toner

Fine pigment powder — fused onto the paper by heat.

🥁

Drum

Photosensitive cylinder — the static image is formed here.

🔥

Fuser

Hot rollers fuse toner onto the paper permanently.

Module 08 · Process

Laser Printing Process

Six phases produce a laser print.

01

Processing

Data is converted to an image.

02

Charging

The drum is negatively charged.

03

Exposing

The laser draws the image (positive).

04

Developing

Toner sticks to the image.

05

Transferring

Toner transfers to the paper.

06

Fusing

Heat fuses the toner.

Module 08 · Inkjet

Inkjet Printers

Ink is sprayed through fine nozzles.

💧

How It Works

  • Ink cartridges (CMYK)
  • Print head & fine nozzles
  • Ink droplets → paper
  • Quality is affected by DPI
⚠️

Common Issues

  • Clogged nozzle → missing streaks
  • Dried ink (not used for a while)
  • Fake "empty" cartridge (chip)
  • Calibration & head cleaning
Module 08 · Others

Thermal, Impact & 3D

🔥

Thermal

Direct thermal (receipts) or thermal transfer (ribbon). No ink/cartridge.

🔨

Impact

Dot matrix — pins strike the ribbon. Suited to carbon copy forms & harsh environments.

🧊

3D

Build physical objects from filament (PLA/ABS) — prototypes, models.

Module 08 · Install

Printer Installation

Install and configure a printer.

🔌

Connection

  • USB — direct connection to a PC
  • Ethernet — network printer
  • Wi-Fi — wireless
  • Bluetooth — mobile devices
🖨️

Driver & Setup

  • Install driver from the vendor
  • Add the printer in the OS
  • Set the default printer
  • Test printing (test page)
Module 08 · Share

Printer Sharing

Share the printer with other users.

🖥️

Share from PC

  • Properties → Sharing → Share
  • Clients connect via \\PC\printer
  • Host PC must be on
🌐

Network Printer

  • Printer with its own IP
  • All clients connect directly
  • No host PC needed
Module 08 · Maintain

Maintenance & Troubleshooting

Routine maintenance prevents printing problems.

🧹

Preventive

  • Clean & vacuum the interior
  • Calibrate the print head
  • Replace toner/cartridge when needed
  • Use quality paper
🩺

Common Problems

  • Paper jam — remove stuck paper
  • Streaks — clean drum/nozzle
  • Nothing prints — check connection, queue, driver
  • Ghosting — replace drum/fuser
Wrap Up

Key Takeaways

🖨️

Match the Tech

Laser for high volume, inkjet for color/photo, thermal for receipts.

🧹

Maintain Regularly

Cleaning & calibration prevent print problems.

🔌

Connect & Share

USB/network/wireless — share correctly, check drivers.

🩺

Troubleshoot Step-by-Step

Queue → connection → driver → hardware — from simple to complex.
