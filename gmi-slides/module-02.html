Module 02 · Prep

Tools & Safety

The right tools and safety practices protect both the components and you.

🛠️

Tools

  • Phillips screwdriver (primary)
  • Flat-head screwdriver
  • Anti-static wrist strap & mat
  • Hex driver & tweezers
⚠️

ESD Protection

  • Wear the wrist strap before touching components
  • Use an ESD mat on the workbench
  • Hold components by their edges
  • Avoid carpets & synthetic clothing
Static electricity (ESD) can damage components without you realizing it — always discharge by touching the metal case first.

Module 02 · Step 2

Motherboard Installation

The main board is installed before the CPU, RAM, and cards.

📐

Preparation

  • Install standoffs in the case
  • Install the I/O shield at the rear of the case
  • Check screw hole alignment
🔩

Mounting

  • Place the motherboard neatly
  • Tighten screws loosely first, then secure
  • Don't overtighten — it can crack
Module 02 · Step 3

CPU & Heat Sink Installation

The most delicate process — installing the CPU wrong can damage the socket and motherboard.

01

Open the socket lever.

02

Match the corner markers.

03

Place the CPU gently.

04

Lock the socket lever.

05

Paste

Apply thermal paste.

06

Fan

Install the cooler & connect power.

Never force the CPU in — it only fits one way. Thermal paste is required for heat transfer to the heatsink.
Module 02 · Step 4

RAM Installation

Installing memory is quick, but it must be neat and correct.

📦

Steps

  • Open the DIMM slot clips
  • Align the module notch with the slot
  • Press evenly until the clips click
  • Dual-channel: install in matching colored slots
⚠️

Common Mistakes

  • Module not pressed in fully (not seated properly)
  • Forcing it the wrong way (there's a notch)
  • Mixing different DDR generations
Module 02 · Step 5

Drive Installation

HDD/SSD install into the bay, M.2 installs directly onto the motherboard.

💾

SATA Drives

  • Install into the drive bay (3.5" / 2.5")
  • Connect the SATA data cable to the board
  • Connect the SATA power cable from the PSU
⚡

M.2 SSD

  • Insert at an angle of ~30°
  • Press down & secure with the screw
  • Check the type: NVMe (PCIe) vs SATA
Module 02 · Step 6

Adapter Cards

Video cards, NICs, and other cards install into PCIe slots.

🎮

Video Card

PCIe x16 slot. Remove the rear bracket first, press in the card, secure with the screw.

🌐

NIC

PCIe x1 slot. Install, secure, connect the network cable.

🔊

Others

Sound/USB/RAID cards — also PCIe x1. Some GPUs need extra power cables.

Module 02 · Step 7

Power & Front Panel Connectors

The final cables power on the system and connect the case buttons and LEDs.

⚡

PSU Cables

  • 24-pin ATX → motherboard
  • 8-pin EPS → CPU power
  • 6/8-pin PCIe → GPU
  • SATA power → drives
🔘

Front Panel

  • Power switch (PWR_SW)
  • Reset switch (RST_SW)
  • Power LED & HDD LED
  • USB & audio header
Consult the motherboard manual — front panel pins aren't standard; wiring them wrong means the computer won't power on.
Module 02 · Step 8

After connecting everything, test the system before closing the case.

01

Press the power button.

02

POST

03

Beep

04

05

A successful POST with no error beeps means the base components work. Now you can close the case & install the operating system.
Wrap Up

Key Takeaways

⚠️

Safety First

Use ESD protection — a single static spark can damage components.

🔩

Gentle & Firm

Install neatly and evenly — never force any component.

📖

Read Manuals

The motherboard manual is the source of truth for pins, slots, and sockets.

🔍

Test Before Close

Test POST and BIOS before closing the case — easier to fix.
