Module 03 · CPU

Advanced CPU Architecture

Technologies inside modern CPUs that boost performance and capability.

🧮

Multi-Core & SMT

Many cores for multitasking. SMT/Hyper-Threading runs 2 threads concurrently per core.

🕹️

Integrated GPU

Many CPUs have onboard graphics (iGPU) — enough for daily work without a video card.

🏠

Virtualization

Support for VT-x (Intel) / AMD-V allows virtual machines to run efficiently.

Module 03 · Firmware

BIOS, UEFI & CMOS

Firmware that powers up the system and stores hardware settings.

🔌

BIOS

Legacy firmware — text interface, MBR boot, basic settings.

🚀

UEFI

Modern standard — graphical interface, GPT boot, Secure Boot, faster boot.

🔋

CMOS Battery

A small battery stores BIOS settings. If weak — time/BIOS lost, hardware redetected every boot.

Symptoms: system clock keeps drifting or BIOS "rediscovers" hardware every boot → replace the CMOS battery.
Module 03 · Memory

Memory Technologies

Memory types, speeds, and features that affect system performance.

🧱

DDR Generations

DDR3 → DDR4 → DDR5. Each generation is faster and more efficient; not cross-compatible.

🛡️

ECC Memory

Error-Correcting Code — detects & corrects data errors. Used in servers.

🔀

Channels

Single, dual, quad-channel — more channels = higher bandwidth for the CPU.

Module 03 · Storage

Storage Technologies

RAID, partitions, and file systems — how data is organized and protected.

🛡️

RAID Levels

  • RAID 0 — striping (performance, no redundancy)
  • RAID 1 — mirroring (full copy)
  • RAID 5 — striping + parity (1 disk can fail)
  • RAID 10 — mirror + stripe (slower but safe)
🗂️

Partition & File Systems

  • NTFS — Windows (permissions, encryption)
  • exFAT — cross-platform portable drives
  • APFS — macOS
  • ext4 — Linux

Module 03 · Peripherals

Peripheral Devices

Input/output devices that interact with the user.

🖥️

Displays

LCD, LED, OLED. Consider resolution, refresh rate, and display connections.

⌨️

Input Devices

Keyboard, mouse, scanner, webcam, microphone — wired or wireless.

🧳

Docking & Hubs

Docking stations & USB hubs add ports for laptops and desktops.

Module 03 · Drivers

Device Drivers

Software that lets the operating system communicate with hardware.

🧩

Role

Translator between the OS and device — without a driver, the hardware won't work.

🔄

Updates

Updates from vendors for fixes, performance, and security.

✍️

Driver Signing

Signed drivers are verified by the manufacturer — avoid unsigned/broken drivers.

Wrap Up

Key Takeaways

Understand cores, threads, iGPU, and virtualization support to choose right.

🛡️

RAID & Backup

RAID provides redundancy, but is not a replacement for backup.

🔋
