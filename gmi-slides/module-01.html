Module 01 · Cases

Computer Cases

Casing melindungi komponen dalaman, menyediakan aliran udara, dan menentukan saiz motherboard yang boleh dipasang.

🏗️

Tower

Berdiri tegak. Full-tower / mid-tower — ruang paling banyak, sesuai untuk desktop yang boleh dikembangkan.

🖥️

Desktop / SFF

Rata dan mendatar. Small Form Factor (SFF) jimat ruang tetapi terhad dari segi pengembangan.

🖱️

All-in-One

Komponen disepadukan dalam monitor — jimat ruang, tetapi sukar dinaik taraf.

Internal Components Overview

Komponen utama yang membentuk sebuah komputer.

🧠

CPU

Otak komputer — memproses arahan dan data.

🗄️

RAM

💾

Storage

HDD/SSD — simpanan data kekal.

⚡

PSU

🔌

🃏

Module 01 · Motherboard

The Motherboard

Papan litar utama yang menyambung semua komponen dan menentukan jenis CPU & RAM yang boleh digunakan.

📐

Form Factors

  • ATX — standard, ruang luas
  • Micro-ATX — lebih kecil
  • Mini-ITX — paling padat
🧩

Key Parts

  • CPU socket (LGA / PGA)
  • Chipset (bridge antara CPU & peranti)
  • RAM slots (DIMM)
  • Expansion slots (PCIe)
  • I/O ports & power connectors
Module 01 · CPU

Central Processing Unit

CPU melaksanakan arahan program. Dua pengeluar utama: Intel dan AMD.

⚡

Sockets

Intel: LGA (pins pada board). AMD: PGA (pins pada CPU) / AM5 LGA. Soket menentukan CPU yang serasi.

🧮

Cores & Threads

Lebih banyak teras = lebih banyak tugas serentak. Hyper-Threading / SMT membenarkan 2 thread per teras.

💨

Cache & Cooling

Cache (L1/L2/L3) = memori pantas dalam CPU. Penyejuk (fan/heatsink) wajib — CPU boleh terlalu panas.

CPU moden menyokong 32-bit dan 64-bit; sistem 64-bit membenarkan RAM melebihi 4 GB.
Module 01 · Memory

RAM — Random Access Memory

Memori sementara yang menyimpan data untuk CPU capai dengan pantas. Data hilang bila kuasa mati (volatile).

🧱

Types

DDR4, DDR5 (generasi terkini). Jangan campur generasi berbeza dalam satu sistem.

📦

Form Factor

DIMM untuk desktop, SO-DIMM untuk laptop. Notch memastikan pemasangan hanya satu arah.

🔀

Channels

Dual-channel menggandakan lebar jalur — pasang modul dalam pasangan untuk prestasi terbaik.

Module 01 · Storage

Storage Devices

Penyimpanan data secara kekal (non-volatile) — sistem operasi, aplikasi dan fail pengguna.

💿

HDD

Platter magnetik berputar. Kapasiti besar, harga murah, lebih perlahan.

⚡

SSD SATA

Flash memory, tiada bahagian bergerak — lebih pantas & tahan lasak.

🚀

NVMe M.2

SSD pada bas PCIe — paling pantas, terus dipasang ke motherboard.

Sambungan storan: SATA (data + power), M.2 (NVMe/SATA), dan pilihan legacy PATA/IDE.
Module 01 · Adapters

Expansion Cards

Kad tambahan dipasang pada slot pengembangan untuk menambah atau meningkatkan keupayaan.

🎮

Video Card

GPU berasingan untuk grafik/prestasi tinggi (gaming, design).

🌐

Network Card

NIC berwayar atau tanpa wayar untuk sambungan rangkaian.

🔊

Sound Card

Audio berkualiti tinggi melebihi audio onboard.

Slot PCIe adalah standard moden (x1, x4, x16). PCI lama hanya untuk perkakasan legacy.
Module 01 · Ports

Ports & Cables

Antara muka untuk menyambung peranti luaran.

🔗

Data & Peripherals

  • USB-A, USB-C (USB 2.0/3.x/4)
  • Thunderbolt (USB-C, sangat pantas)
  • eSATA untuk storan luaran
  • RJ45 untuk Ethernet
🖥️

Display

  • HDMI — audio + video
  • DisplayPort — monitor resolusi tinggi
  • DVI & VGA — legacy
  • 3.5mm audio jack
Module 01 · Power

Power Supply Unit

Menukar arus ulang-alik (AC) kepada arus terus (DC) yang diperlukan komponen.

⚡

Wattage

Pilih watt yang mencukupi untuk semua komponen — GPU gaming perlukan lebih kuasa.

🏅

80 PLUS

Pensijilan kecekapan tenaga — lebih tinggi (Bronze→Titanium), kurang haba dibazirkan.

🔌

Connectors

24-pin (board), 8-pin CPU, 6/8-pin GPU, SATA power, Molex.

Wrap Up

Key Takeaways

🧩

Compatibility

CPU, RAM dan motherboard mesti serasi — semak soket, chipset dan jenis memori.

⚡

Power Matters

PSU berkualiti dengan watt cukup melindungi semua komponen.

💾

Storage Choices

HDD untuk kapasiti, SSD/NVMe untuk kelajuan — gabungkan mengikut keperluan.

🔌

Know Your Ports

USB-C & Thunderbolt semakin menjadi standard untuk kelajuan dan serba guna.
