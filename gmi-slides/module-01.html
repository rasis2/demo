Module 01 · Cases

Computer Cases

The case protects internal components, provides airflow, and determines what motherboard size can be installed.

🏗️

Tower

Stands upright. Full-tower / mid-tower — the most room, ideal for expandable desktops.

🖥️

Desktop / SFF

Flat and horizontal. Small Form Factor (SFF) saves space but limits expansion.

🖱️

All-in-One

Components are built into the monitor — saves space, but hard to upgrade.

Module 01 · Motherboard

The Motherboard

The main circuit board that connects all components and determines which CPU & RAM can be used.

📐

Form Factors

  • ATX — standard, roomy
  • Micro-ATX — smaller
  • Mini-ITX — most compact
🧩

Key Parts

  • CPU socket (LGA / PGA)
  • Chipset (bridge between CPU & devices)
  • RAM slots (DIMM)
  • Expansion slots (PCIe)
  • I/O ports & power connectors
Module 01 · CPU

Central Processing Unit

The CPU executes program instructions. Two main manufacturers: Intel and AMD.

⚡

Sockets

Intel: LGA (pins on the board). AMD: PGA (pins on the CPU) / AM5 LGA. The socket determines compatible CPUs.

🧮

Cores & Threads

More cores = more simultaneous tasks. Hyper-Threading / SMT allows 2 threads per core.

💨

Cache & Cooling

Cache (L1/L2/L3) = fast memory inside the CPU. Cooling (fan/heatsink) is mandatory — CPUs can overheat.

Modern CPUs support 32-bit and 64-bit; 64-bit systems allow RAM beyond 4 GB.
Module 01 · Memory

RAM — Random Access Memory

Temporary memory that holds data for fast CPU access. Data is lost when power goes off (volatile).

🧱

Types

DDR4, DDR5 (latest generation). Don't mix different generations in one system.

📦

Form Factor

DIMM for desktops, SO-DIMM for laptops. The notch ensures installation fits only one way.

🔀

Channels

Dual-channel doubles bandwidth — install modules in pairs for the best performance.

Module 01 · Storage

Storage Devices

Permanent (non-volatile) data storage — operating system, applications, and user files.

💿

HDD

Rotating magnetic platters. Large capacity, low cost, slower.

⚡

SSD SATA

Flash memory, no moving parts — faster & more durable.

🚀

NVMe M.2

SSD on the PCIe bus — fastest, installed directly onto the motherboard.

Storage connections: SATA (data + power), M.2 (NVMe/SATA), and legacy PATA/IDE options.
Module 01 · Adapters

Expansion Cards

Add-on cards installed in expansion slots to add or improve capability.

🎮

Video Card

Dedicated GPU for high-performance graphics (gaming, design).

🌐

Network Card

Wired or wireless NIC for network connections.

🔊

Sound Card

High-quality audio beyond onboard audio.

PCIe slots are the modern standard (x1, x4, x16). Old PCI is only for legacy hardware.
Module 01 · Ports

Ports & Cables

Interfaces for connecting external devices.

🔗

Data & Peripherals

  • USB-A, USB-C (USB 2.0/3.x/4)
  • Thunderbolt (USB-C, very fast)
  • eSATA for external storage
  • RJ45 for Ethernet
🖥️

Display

  • HDMI — audio + video
  • DisplayPort — high-resolution monitors
  • DVI & VGA — legacy
  • 3.5mm audio jack
Module 01 · Power

Power Supply Unit

Converts alternating current (AC) into the direct current (DC) components need.

⚡

Wattage

Choose enough wattage for all components — gaming GPUs need more power.

🏅

80 PLUS

Energy-efficiency certification — the higher (Bronze→Titanium), the less wasted heat.

🔌

Connectors

24-pin (board), 8-pin CPU, 6/8-pin GPU, SATA power, Molex.

Wrap Up

Key Takeaways

🧩

Compatibility

CPU, RAM, and motherboard must be compatible — check the socket, chipset, and memory type.

⚡

Power Matters

A quality PSU with enough wattage protects all components.

💾

Storage Choices

HDD for capacity, SSD/NVMe for speed — combine as needed.

🔌

Know Your Ports

USB-C & Thunderbolt are becoming the standard for speed and versatility.
