Module 05 · Types

Types of Networks

Networks are classified by size and geographic scope.

👤

PAN — Personal

Very small — personal devices connected via Bluetooth/USB (phone → earbuds, laptop → phone).

🏠

LAN — Local

One building/location — home, office, school. Connected by switches & routers.

📶

WLAN — Wireless LAN

Wireless LAN using Wi-Fi (IEEE 802.11).

🌍

WAN — Wide

Spans cities/countries — the internet itself is the largest WAN.

Module 05 · Topologies

Network Topologies

Physical/logical arrangement of how devices are connected.

⭐

Star

All devices connect to a center (switch). Most common — one broken cable doesn't affect others.

🕸️

Mesh

Each device connects to many others — highly resilient, expensive.

🚌

Bus / Ring

Legacy. Bus: one shared cable. Ring: devices in a loop.

🔀

Hybrid

A combination of topologies — most common in real networks.

Module 05 · Media

Network Media

The physical channel that carries data.

🟤

Copper

UTP/STP (twisted pair) — Ethernet. RJ45, max ~100m. Cheap & easy.

✨

Fiber Optic

Light through glass — very fast, long distance, immune to electrical interference.

📡

Wireless

Radio waves (Wi-Fi, Bluetooth, cellular) — portable, can be interfered with.

Module 05 · Models

OSI & TCP/IP Models

Network models for understanding how data travels.

📚

OSI (7 Layers)

  • 7 Application · 6 Presentation
  • 5 Session · 4 Transport
  • 3 Network · 2 Data Link · 1 Physical
🌐

TCP/IP (4 Layers)

  • Application (HTTP, DNS, SMTP)
  • Transport (TCP / UDP)
  • Internet (IP, ICMP)
  • Network Access (Ethernet)
Remember OSI: "Please Do Not Throw Sausage Pizza Away" — Physical→Application.

Module 05 · IP

IP Addressing

A unique address for every device on a network.

🔢

IPv4

  • 32-bit: 192.168.1.10
  • Private: 10.x, 172.16–31.x, 192.168.x
  • Subnet mask: 255.255.255.0
  • NAT translates private→public
🔤

IPv6

  • 128-bit: 2001:db8::1
  • Plenty of addresses — no NAT required
  • Solves the IPv4 shortage
Module 05 · Services

DNS, DHCP & NAT

Network services that make the internet work.

📖

DNS

Domain Name System — translates names (google.com) into IP addresses.

🤝

DHCP

Automatically assigns IP address, gateway & DNS to devices.

🔀

NAT

Translates private IPs to public — many devices share one internet address.
