Module 05 · Types

Types of Networks

Rangkaian dikelaskan mengikut saiz dan skop geografi.

👤

PAN — Personal

Sangat kecil — peranti peribadi bersambung Bluetooth/USB (telefon → earbuds, laptop → telefon).

🏠

LAN — Local

Satu bangunan/lokasi — rumah, pejabat, sekolah. Disambung switch & router.

📶

WLAN — Wireless LAN

LAN tanpa wayar menggunakan Wi-Fi (IEEE 802.11).

🌍

WAN — Wide

Merentasi bandar/negara — internet itu sendiri ialah WAN terbesar.

Module 05 · Topologies

Network Topologies

Susunan fizikal/logik bagaimana peranti disambung.

⭐

Star

Semua peranti ke pusat (switch). Paling biasa — satu kabel putus tidak jejaskan lain.

🕸️

Mesh

Setiap peranti bersambung ke banyak peranti — sangat berdaya tahan, mahal.

🚌

Bus / Ring

Legacy. Bus: satu kabel dikongsi. Ring: peranti dalam gelung.

🔀

Hybrid

Gabungan topologi — paling biasa dalam rangkaian sebenar.

Module 05 · Media

Network Media

Saluran fizikal yang membawa data.

🟤

Copper

UTP/STP (twisted pair) — Ethernet. RJ45, maks ~100m. Murah & mudah.

✨

Fiber Optic

Cahaya melalui kaca — sangat pantas, jarak jauh, kebal gangguan elektrik.

📡

Wireless

Gelombang radio (Wi-Fi, Bluetooth, cellular) — mudah alih, boleh diganggu.

Module 05 · Models

OSI & TCP/IP Models

Model rangkaian untuk memahami bagaimana data bergerak.

📚

OSI (7 Layers)

  • 7 Application · 6 Presentation
  • 5 Session · 4 Transport
  • 3 Network · 2 Data Link · 1 Physical
🌐

TCP/IP (4 Layers)

  • Application (HTTP, DNS, SMTP)
  • Transport (TCP / UDP)
  • Internet (IP, ICMP)
  • Network Access (Ethernet)
Ingat OSI: "Please Do Not Throw Sausage Pizza Away" — Physical→Application.

Module 05 · IP

IP Addressing

Alamat unik untuk setiap peranti dalam rangkaian.

🔢

IPv4

  • 32-bit: 192.168.1.10
  • Private: 10.x, 172.16–31.x, 192.168.x
  • Subnet mask: 255.255.255.0
  • NAT menukar private→public
🔤

IPv6

  • 128-bit: 2001:db8::1
  • Banyak alamat — tiada NAT diperlukan
  • Penyelesaian kekurangan IPv4
Module 05 · Services

DNS, DHCP & NAT

Perkhidmatan rangkaian yang menjadikan internet berfungsi.

📖

DNS

Domain Name System — menukar nama (google.com) kepada alamat IP.

🤝

DHCP

Memberi alamat IP, gateway & DNS secara automatik kepada peranti.

🔀

NAT

Menukar IP private kepada public — banyak peranti kongsi satu alamat internet.
