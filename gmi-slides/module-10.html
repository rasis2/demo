Module 10 · Methods

Installation Methods

Choose a method based on the situation.

🧹

Clean Install

  • Delete partitions & install fresh
  • Cleanest — no leftover issues
  • Back up data first!
⬆️

Upgrade

  • Keeps files, apps & settings
  • From an existing Windows version/edition
  • Upgrade path must be supported
📦

Image Deployment

  • Preinstalled Windows image (WIM)
  • Fast for many PCs
  • Use Sysprep & MDT/SCCM
Module 10 · Partition

Partitioning: MBR vs GPT

Disk structure determines limits and boot compatibility.

🕰️

MBR

  • Legacy BIOS
  • Max 4 primary partitions
  • 2 TB limit
🚀

GPT

  • UEFI — modern standard
  • Many partitions (128+)
  • Exceeds 2 TB
Windows system files: NTFS — supports permissions, compression & encryption (EFS/BitLocker).
