Module 09 · Basics

Virtualization Basics

Running multiple operating systems on one physical machine.

🖥️

Virtual Machine (VM)

  • A virtual computer in software
  • Its own OS (guest OS)
  • Resources allocated: CPU, RAM, disk
🧑‍✈️

Hypervisor

  • Software that manages VMs
  • Type 1 — bare-metal (VMware ESXi, Hyper-V)
  • Type 2 — hosted (VirtualBox, VMware Workstation)
Module 09 · Benefits

Benefits of Virtualization

Why organizations use virtualization widely.

📦

Consolidation

Many physical servers → a few hosts — saves cost & energy.

🔒

Isolation

Each VM is isolated — one failing doesn't affect the others.

🧪

Testing & Dev

Test OS/apps in a safe environment without risking the main system.

A snapshot lets a VM return to a previous state quickly.
Module 09 · Requirements

Virtualization Requirements

Hardware must support virtualization well.

🧠

CPU

Virtualization extensions — Intel VT-x / AMD-V. More cores = better.

🗄️

RAM

Each VM needs its own memory — total RAM determines how many VMs run at once.

💾

Storage

Space for VM files (vmdk/vhdx) — SSDs speed up VM performance.
