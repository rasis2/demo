Module 09 · Basics

Virtualization Basics

Menjalankan berbilang sistem operasi pada satu perkakasan fizikal.

🖥️

Virtual Machine (VM)

  • Komputer maya dalam perisian
  • OS sendiri (guest OS)
  • Sumber diagih: CPU, RAM, disk
🧑‍✈️

Hypervisor

  • Perisian pengurus VM
  • Type 1 — bare-metal (VMware ESXi, Hyper-V)
  • Type 2 — hosted (VirtualBox, VMware Workstation)
Module 09 · Benefits

Benefits of Virtualization

Mengapa organisasi menggunakan virtualisasi secara meluas.

📦

Consolidation

Banyak server fizikal → beberapa hos — jimat kos & tenaga.

🔒

Isolation

Setiap VM terasing — kegagalan satu tidak jejaskan yang lain.

🧪

Testing & Dev

Uji OS/app dalam persekitaran selamat tanpa risiko pada sistem utama.

Snapshot membolehkan VM kembali ke keadaan sebelumnya dengan cepat.
Module 09 · Requirements

Virtualization Requirements

Perkakasan perlu menyokong virtualisasi dengan baik.

🧠

CPU

Virtualization extensions — Intel VT-x / AMD-V. Banyak teras = lebih baik.

🗄️

RAM

Setiap VM perlukan memori sendiri — jumlah RAM menentukan bilangan VM serentak.

💾

Storage

Ruang untuk fail VM (vmdk/vhdx) — SSD mempercepatkan prestasi VM.

On-Demand

Cloud Deployment
