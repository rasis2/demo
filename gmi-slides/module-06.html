Module 06 · Devices

Network Devices

Hardware that builds and connects networks.

💳

NIC

Network Interface Card — connects a device to the network (wired/wireless).

🔀

Switch

Connects devices in a LAN — forwards data to a specific destination.

🧭

Router

Connects different networks (LAN→WAN/internet) and makes routing decisions.

📡

Access Point

Provides Wi-Fi for wireless devices.

🛡️

Firewall

Filters incoming/outgoing traffic based on security rules.

📠

Modem

Converts ISP signals (cable/fiber/DSL) into network data.

Module 06 · Cables

Copper Cable Types

UTP cable choice depends on the type of devices being connected.

CableWiringUse
Straight-throughT568A↔T568A / T568B↔T568BDifferent devices (PC↔switch)
CrossoverT568A↔T568BSame devices (PC↔PC, switch↔switch)
RolloverReversed wiringConsole to router/switch (RJ45→serial)
T568A & T568B standards — identify the wire arrangement for correct connections.
Module 06 · Wiring

Terminating UTP

Installing RJ45 connectors and jacks correctly.

🔧

RJ45 Connector

  • Strip the outer cable jacket (~1.5cm)
  • Straighten wires per T568A/B
  • Insert into RJ45 & crimp with a crimper
  • Test with a cable tester
🧱

Wall Jack / Patch Panel

  • Use a punch-down tool
  • Follow the color code on the jack
  • Make sure wires are neat & secure
Module 06 · Config

Wired Network Configuration

IP settings so devices can communicate on a network.

🤝

DHCP (Automatic)

  • Router assigns IP, subnet, gateway, DNS
  • No manual configuration
  • Suitable for most users
✍️

Static IP (Manual)

  • IP, subnet mask, default gateway, DNS
  • For servers, network printers
  • Avoids IP conflicts
Check with ipconfig (Windows) / ifconfig (Linux/macOS).
Module 06 · Wireless

Wireless Configuration

Key settings on a wireless access point / router.

📶

SSID

Wireless network name — change from the default, can be hidden.

🔐

Security

WPA2/WPA3 with a strong password — avoid WEP (insecure).

📻

Channel

Choose a less congested channel (2.4GHz vs 5GHz/6GHz).

Module 06 · Sharing

Network Sharing

Sharing files, folders, and printers on a network.

📁

File Sharing

  • Workgroup / domain
  • Share folders with permissions (read/write)
  • Access via \\PC-NAME\share
🖨️

Printer Sharing

  • Share a printer from one PC
  • Or a network printer with its own IP
  • Install drivers on each client
