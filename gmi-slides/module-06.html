Module 06 · Devices

Network Devices

Perkakasan yang membina dan menghubungkan rangkaian.

💳

NIC

Network Interface Card — sambungan peranti ke rangkaian (berwayar/wayarles).

🔀

Switch

Menyambung peranti dalam LAN — menghantar data ke destinasi spesifik.

🧭

Router

Menghubungkan rangkaian berbeza (LAN→WAN/internet) dan membuat keputusan laluan.

📡

Access Point

Menyediakan Wi-Fi untuk peranti wayarles.

🛡️

Firewall

Menapis trafik masuk/keluar berdasarkan peraturan keselamatan.

📠

Modem

Menukar isyarat ISP (kabel/fiber/DSL) kepada data rangkaian.

Module 06 · Cables

Copper Cable Types

Pemilihan kabel UTP bergantung pada jenis peranti yang disambung.

KabelSusunanKegunaan
Straight-throughT568A↔T568A / T568B↔T568BPeranti berbeza (PC↔switch)
CrossoverT568A↔T568BPeranti sama (PC↔PC, switch↔switch)
RolloverSusunan songsangKonsol ke router/switch (RJ45→serial)
Standard T568A & T568B — kenal pasti susunan wayar untuk sambungan yang betul.
Module 06 · Wiring

Terminating UTP

Memasang konektor RJ45 dan soket dengan betul.

🔧

RJ45 Connector

  • Buka sarung luar kabel (~1.5cm)
  • Luruskan wayar mengikut T568A/B
  • Masukkan ke RJ45 & tekan dengan crimper
  • Uji dengan cable tester
🧱

Wall Jack / Patch Panel

  • Gunakan punch-down tool
  • Ikut kod warna di soket
  • Pastikan wayar kemas & tidak tertanggal
Module 06 · Config

Wired Network Configuration

Tetapan IP supaya peranti berkomunikasi dalam rangkaian.

🤝

DHCP (Automatik)

  • Router memberi IP, subnet, gateway, DNS
  • Tiada konfigurasi manual
  • Sesuai untuk kebanyakan pengguna
✍️

Static IP (Manual)

  • IP, subnet mask, default gateway, DNS
  • Untuk server, printer rangkaian
  • Elak konflik IP
Semak dengan ipconfig (Windows) / ifconfig (Linux/macOS).
Module 06 · Wireless

Wireless Configuration

Tetapan penting pada access point / router wayarles.

📶

SSID

Nama rangkaian wayarles — tukar dari default, boleh disembunyikan.

🔐

Security

WPA2/WPA3 dengan kata laluan kuat — elak WEP (tidak selamat).

📻

Channel

Pilih saluran kurang gangguan (2.4GHz vs 5GHz/6GHz).

Module 06 · Sharing

Network Sharing

Berkongsi fail, folder dan printer dalam rangkaian.

📁

File Sharing

  • Workgroup / domain
  • Kongsi folder dengan kebenaran (read/write)
  • Akses via \\PC-NAME\share
🖨️

Printer Sharing

  • Kongsi printer dari satu PC
  • Atau printer rangkaian dengan IP sendiri
  • Pasang driver pada setiap klien

Wrap Up

Key Takeaways

🔀

Devices & Roles

Switch dalam LAN, router antara rangkaian, AP untuk wayarles.

🔌

Wire It Right

T568A/B, straight/crossover — kabel betul = sambungan betul.

🔐

Secure Wi-Fi

WPA2/WPA3 + SSID tersembunyi + kata laluan kuat.

🩺

Diagnose Systematically

ping → ipconfig → tracert → ganti kabel/port.
