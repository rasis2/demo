Module 11 · Users

Users & Groups

Kawal siapa yang boleh menggunakan komputer dan bagaimana.

👤

User Accounts

Admin (kawalan penuh) atau Standard (terhad). Tukar kata laluan & jenis.

👥

Groups

Administrators, Users, Guests — kebenaran diberikan kepada kumpulan.

🔑

Passwords

Kuat, unik & kerap ditukar. Guna Windows Hello (PIN, biometric).

Module 11 · Permissions

Permissions & Sharing

Kawal akses kepada fail dan folder.

📄

NTFS Permissions

  • Read, Write, Modify, Full Control
  • Ditetapkan pada fail/folder
  • Kekal walaupun fail dipindah dalam NTFS
🔗

Share Permissions

  • Untuk akses rangkaian
  • Read / Change / Full Control
  • Kebenaran berkesan = gabungan paling ketat

💽

Partitions

Cipta, padam, ubah saiz partition (C:, D:, dll).

🧱

Format

NTFS, exFAT, FAT32. Label & letter drive.

🩺

Disk Status

Healthy, Unallocated, Offline — semak kesihatan cakera.

Module 11 · Backup

Backup & Restore

Lindungi data dan pulihkan sistem bila perlu.

🕰️

File History

Backup fail pengguna secara automatik ke pemacu lain.

🔄

System Restore

Pulihkan Windows ke restore point — tanpa jejaskan fail.

💿

System Image

Imej penuh cakera — pulihkan keseluruhan sistem.

Module 11 · Troubleshoot

Troubleshooting Windows

Isu biasa & langkah penyelesaian.

MasalahPenyelesaian
Boot lambatSemak startup apps, disk health
Blue Screen (BSOD)Semak driver, RAM, minidump
App tidak berfungsiKemas kini, repair/reinstall
Kata laluan terlupaReset via akun MS / recovery
Sistem tidak responsifRestart, Task Manager, safe mode
Update gagalWindows Update troubleshooter
Wrap Up

Key Takeaways

🎛️

Know Both UIs

Settings moden + Control Panel — setiap tetapan ada tempatnya.

👥

Control Access

Pengguna, kumpulan & kebenaran NTFS/Share mengawal keselamatan.

💾

Backup Always

File History + System Restore + image — berlapis-lapis perlindungan.

🩺

Diagnose Systematically

Device Manager → Event Viewer → safe mode → repair.
