Control Panel & Settings

Two main interfaces for configuring Windows.

Settings

  • Modern interface (Win+I)

🗂️

Control Panel

  • Legacy — all applets
  • System, Users, Programs

Module 11 · Users

Users & Groups

Control who can use the computer and how.

👤

User Accounts

Admin (full control) or Standard (limited). Change password & type.

👥

Groups

Administrators, Users, Guests — permissions are assigned to groups.

🔑

Passwords

Strong, unique & changed often. Use Windows Hello (PIN, biometric).

Module 11 · Permissions

Permissions & Sharing

Control access to files and folders.

📄

NTFS Permissions

  • Read, Write, Modify, Full Control
  • Set on files/folders
  • Persist even if files are moved within NTFS
🔗

Share Permissions

  • For network access
  • Read / Change / Full Control
  • Effective permission = most restrictive combination
Module 11 · Disks

Disk Management

Manage disks and partitions in Windows.

💽

Partitions

Create, delete, resize partitions (C:, D:, etc.).

🧱

Format

NTFS, exFAT, FAT32. Drive label & letter.

🩺

Disk Status

Healthy, Unallocated, Offline — check disk health.

Module 11 · Tools

System Tools

Key tools for monitoring & managing the system.

🔧

Management

  • Device Manager — hardware & drivers
  • Task Manager — processes & performance
  • Event Viewer — system logs
⚙️

Utilities

  • msconfig — startup & boot
  • services.msc — services
  • regedit — registry (be careful!)
Module 11 · Backup

Backup & Restore

Protect data and recover the system when needed.

🕰️

File History

Automatically backs up user files to another drive.

🔄

System Restore

Restore Windows to a restore point — without affecting files.

💿

System Image

Full disk image — restore the entire system.
