Module 12 · Linux

Linux Overview

Open-source OS — Linux kernel + free software.

🐧

Open Source

Free, open code, large community. Distributed as distributions (distros).

📦

Distributions

Ubuntu, Debian, Fedora, CentOS, Mint — different desktops & package managers.

🖥️

Uses

Servers, desktop, embedded, supercomputers — very stable & secure.

Module 12 · Filesystem

Linux Filesystem

Hierarchical structure starting from the root (/).

DirectoryPurpose
/Root — top of everything
/homeUser personal files
/etcSystem configuration files
/varVariable data (logs, cache)
/bin, /usrPrograms & utilities
/devDevices (disks, USB)
Module 12 · CLI

Linux CLI Basics

Essential commands for administrators.

⌨️

Navigation & Files

  • pwd — current location
  • ls — list files
  • cd — change directory
  • cp / mv / rm — copy/move/delete
🛡️

Permissions & Admin

  • sudo — run with admin rights
  • chmod — change permissions
  • chown — change owner
  • grep — search text in output
Module 12 · macOS

macOS Overview

Apple's operating system — Unix-based, tightly controlled.

🍎

Unix-Based

Stable & secure — full terminal for advanced users.

🔍

Spotlight

Fast search of files, apps & info across the system.

🕰️

Time Machine

Automatic backup to an external drive — easy restore.

Module 12 · macOS Tools

macOS Tools

Essential utilities in macOS.

📁

Finder

macOS file manager — similar to File Explorer.

💽

Disk Utility

Format & manage disks — similar to Disk Management.

⚙️

System Settings

System configuration — similar to Windows Settings.

🔧

Terminal

Unix CLI — similar Linux commands can be used.

Android & iOS

The two main mobile operating systems.

🤖

Android

  • Google — many manufacturers
  • Play Store, APK sideload
  • Updates vary by manufacturer
🍎

iOS

  • Apple — integrated hardware & OS
  • App Store only
  • Consistent, long-term updates
