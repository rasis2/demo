Module 12 · Linux

Linux Overview

Open Source

Percuma, kod terbuka, komuniti besar. Diedarkan sebagai distribusi (distro).

📦

Distributions

Ubuntu, Debian, Fedora, CentOS, Mint — berbeza desktop & pengurusan pakej.

Uses

Server, desktop, embedded, superkomputer — sangat stabil & selamat.

Module 12 · Filesystem

Linux Filesystem

Struktur hierarki bermula dari akar (/).

DirektoriKegunaan
/Akar — puncak semua
/homeFail peribadi pengguna
/etcFail konfigurasi sistem
/varData berubah (log, cache)
/bin, /usrProgram & utiliti
/devPeranti (disks, usb)
Module 12 · CLI

Linux CLI Basics

Arahan penting untuk pentadbir.

⌨️

Navigation & Files

  • pwd — lokasi semasa
  • ls — senarai fail
  • cd — tukar direktori
  • cp / mv / rm — salin/pindah/padam
🛡️

Permissions & Admin

  • sudo — jalan dengan hak admin
  • chmod — tukar kebenaran
  • chown — tukar pemilik
  • grep — cari teks dalam output
